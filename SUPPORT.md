# Support

## Usage questions

Ask setup, configuration, and usage questions in the [GitHub Discussions Q&A category](https://github.com/beingmartinbmc/jambavan/discussions/categories/q-a). Include the Jambavan version, MCP host, operating system, Node version, and sanitized diagnostics when relevant.

## Bugs and feature requests

Use the repository's [issue forms](https://github.com/beingmartinbmc/jambavan/issues/new/choose) for reproducible bugs and focused feature requests. Search existing issues first and remove private paths, source, memory, credentials, and secrets from reports.

## Security vulnerabilities

Do not report vulnerabilities in Discussions or issues. Follow [SECURITY.md](SECURITY.md) and use [GitHub private vulnerability reporting](https://github.com/beingmartinbmc/jambavan/security/advisories/new).
